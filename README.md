 🧭 موتور تخمین هزینه سفر — مبدا تبریز

یک وب‌اپ ساده و سبک که هزینه سفر از **تبریز** به شهرهای استان آذربایجان شرقی را محاسبه می‌کند و آن‌ها را بر اساس «به‌صرفه بودن» رتبه‌بندی می‌کند.

 ✨ امکانات

- 🚗 **سه نوع حمل‌ونقل:** خودرو شخصی، اتوبوس، قطار
- 💰 **محاسبه کامل هزینه‌ها:** حمل‌ونقل + اقامت + خوراک + جاذبه + سوغات
- ⛽ **محاسبه دقیق سوخت** با احتساب سه پله سهمیه بنزین
- 🏡 **اقامت به‌صورت بازه‌ای** برای واقع‌گرایی بیشتر
- 🏆 **امتیاز ۰ تا ۱۰۰** بر اساس بودجه، جاذبه‌ها و مسافت
- 🥇 **سه پیشنهاد هوشمند:** اقتصادی‌ترین، بهترین ارزش، بیشترین گردش
- 📱 **طراحی واکنش‌گرا** برای موبایل و دسکتاپ
- 🎨 **تم الهام‌گرفته از کاشی مسجد کبود تبریز**
